## Kognitiv Python SDK
POWERED BY KOGNITIV ANALYTICA
The official Python SDK for **Kognitiv Core API**, designed for educational institutions and AI-powered applications.

It provides a simple, fast, and scalable interface to integrate advanced AI capabilities into your systems.

---

##  Features

-  Chat completions 
-  Data analysis (statistics, trends, forecasting)
-  Multi-agent workflows
-  Streaming responses
-  Usage monitoring & quotas
-  Built-in error handling
